60-30-10 Rule for Balanced UI Color Schemes

The 60-30-10 rule is a classic design principle adapted from interior decor to create visually balanced, accessible user interfaces. By dividing an interface's color palette into 60% dominant color, 30% secondary color, and 10% accent color, designers establish an intuitive visual hierarchy that guides the user's eye effortlessly. This article breaks down how to allocate these color proportions effectively to eliminate visual clutter, highlight critical interactions, and streamline digital product design.

The 60%: The Dominant Base

The dominant color covers approximately 60% of the screen real estate and serves as the visual anchor of the layout.

  • Application: In UI design, this is typically your background canvas, large whitespace areas, or main page containers.
  • Selection: The dominant color is usually a neutral shade—such as off-white, light gray, or dark slate for dark mode.
  • Purpose: It sets the general atmosphere of the application without competing for attention. A calm, neutral base prevents visual fatigue and gives the interface breathing room.

The 30%: The Secondary Structure

The secondary color accounts for about 30% of the interface and introduces depth, structure, and readability.

  • Application: This color is used for structural UI components such as navigation menus, sidebars, cards, headers, borders, and primary body text.
  • Selection: It should contrast enough with the dominant 60% base to distinguish functional regions, but remain subtle enough not to distract from primary actions.
  • Purpose: It frames the content, groups related information together, and establishes readable typographic contrast across the screen.

The 10%: The Accent for Action

The remaining 10% is dedicated to an accent color that provides maximum visual punch.

  • Application: Reserve this color strictly for high-priority interactive elements, such as primary Call-to-Action (CTA) buttons, progress indicators, selected states, badges, and critical alerts.
  • Selection: This is typically a vibrant brand color that strongly contrasts with both the 60% base and the 30% secondary elements.
  • Purpose: By limiting the accent color to 10%, you avoid "accent inflation." When an intense color is used sparingly, users instinctively recognize it as an interactive or important element, drastically reducing cognitive load.

Practical Steps to Apply the Rule

  1. Start with Grayscale: Build the interface in shades of gray to balance the 60% base and 30% structure before introducing brand colors. If the layout works in monochrome, the color balance will succeed.
  2. Assign One True Accent: Pick a single distinct hue for the 10% allocation. If secondary interactive states are needed, use shades or tints of that same hue rather than adding extra colors.
  3. Verify Contrast Ratios: Ensure the 10% accent color meets WCAG guidelines against both the 60% and 30% backgrounds so buttons and vital indicators remain accessible to all users.
